# MC2<a name="ZH-CN_TOPIC_0000002114052025"></a>

## Description<a name="zh-cn_topic_0000001935420684_zh-cn_topic_0000001526594958_zh-cn_topic_0000001525424352_section36583473819"></a>

Registers this operator as a compute-communication fusion operator. Calling this API returns an [OpMC2Def](../OpMC2Def/OpMC2Def.md) structure, through which you can subsequently configure the communication domain name.

## Prototype<a name="zh-cn_topic_0000001935420684_zh-cn_topic_0000001526594958_zh-cn_topic_0000001525424352_section13230182415108"></a>

```
OpMC2Def &MC2(void)
```

## Parameters<a name="zh-cn_topic_0000001935420684_zh-cn_topic_0000001526594958_zh-cn_topic_0000001525424352_section75395119104"></a>

None

## Return Value<a name="zh-cn_topic_0000001935420684_zh-cn_topic_0000001526594958_zh-cn_topic_0000001525424352_section25791320141317"></a>

Returns the [OpMC2Def](../OpMC2Def/OpMC2Def.md) structure, which can subsequently be used to configure the communication domain name.

## Constraints<a name="zh-cn_topic_0000001935420684_zh-cn_topic_0000001526594958_zh-cn_topic_0000001525424352_section19165124931511"></a>

A custom operator project generated based on an earlier CANN package (which does not support the MC2 feature) is incompatible with the MC2 API. When using a custom operator project generated by a CANN package other than the current version, pay special attention to compatibility. You can check whether the current project supports this feature by checking whether the \_build\_mc2\_ctx field exists in the cmake/util/ascendc\_impl\_build.py file in the custom operator project. If the field is not found, regenerate the custom operator project to enable the MC2 feature.
