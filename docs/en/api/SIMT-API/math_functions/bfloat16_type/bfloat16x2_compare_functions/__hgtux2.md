## Description

The header file path is `"simt_api/asc_bf16.h"`.

Compares the two components of two bfloat16x2\_t values. If a component of the first value is greater than the corresponding component of the second value, the comparison result is 1.0; otherwise, it is 0.0. If any input component is nan, the comparison result for that component is 1.0.

## Prototype

```cpp
bfloat16x2_t __hgtux2(bfloat16x2_t x, bfloat16x2_t y)
```

## Parameters

**Table 1**  Parameters

| Name | Input/Output | Description |
| --- | --- | --- |
| x | Input | Source operand. |
| y | Input | Source operand. |

## Return Value

Returns, for each component of the input data, the result of comparing whether the first number is greater than the second number: 1.0 if the condition is satisfied, and 0.0 otherwise. Special values are as follows:

| x Component Value | y Component Value | Corresponding Component Return Value |
|---|---|---|
| nan | Any value | 1.0 |
| Any value | nan | 1.0 |
| inf | inf | 0 |
| ±0 | ±0 | 0 |

## Constraints

None
