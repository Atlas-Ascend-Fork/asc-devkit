## Description

`AscendC::TensorDataType` is a type alias of `ge::DataType`, used to describe the Tensor data type used by the Host-side Tiling API of the high-level API.

For details, see [ge::DataType](https://gitcode.com/cann/metadef/blob/9.2.0/docs/en/api/ge_namespace/DataType.md).
