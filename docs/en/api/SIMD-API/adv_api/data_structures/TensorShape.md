## Description

`AscendC::TensorShape` is a type alias of `ge::Shape`, used to describe the tensor shape used by the Host-side Tiling API of the high-level API.

For details, see [ge::Shape](https://gitcode.com/cann/metadef/blob/9.2.0/docs/en/api/ge_namespace/shape/Shape.md).
