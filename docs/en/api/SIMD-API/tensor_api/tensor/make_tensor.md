## Description

The header file path is `tensor_api/tensor.h`.

make_tensor binds a memory pointer (generated by [make_mem_ptr](make_mem_ptr.md)) with a layout object (generated by [make_frame_layout](../layout/make_frame_layout.md)/[make_layout](../layout/make_layout.md)) to produce a Tensor object with complete type information.

make_tensor automatically derives whether to return a global_tensor or a local_tensor based on the physical location marker of the memory pointer. When the pointer's physical location is in Global Memory (external storage), it returns a global_tensor; when the pointer's location is in Local Memory (internal storage) on the AI Core, it returns a local_tensor.

The generated Tensor object can be passed directly to APIs such as copy (movement) and mmad (cube computation). The compiler automatically selects the underlying hardware instruction based on the physical location marker in its Engine and the layout mode in the layout.

## Function Prototype

```cpp
template <typename Iterator, typename... Args>
__aicore__ inline auto make_tensor(const Iterator& iter, const Args&... args)
```

## Parameters

**Table 1**  Parameters

| Parameter  | Input/Output | Description |
| :----- | :------- | :------- |
| iter | Input | Iterator, which requires a view_engine object to be passed in and is used to create the Tensor. The return type is determined by the memory location bound to this iterator. |
| args... | Input | Variadic parameters, which currently support passing one or two parameters.<br>&bull;When one parameter is passed: Creates the Tensor based on the passed layout object.<br>&bull;When two parameters are passed: Builds a layout object based on the passed parameters, and creates the Tensor based on that layout. |

## Return Value

- Returns a tensor object of type `global_tensor<Engine, Layout>` or `local_tensor<Engine, Layout>`, determined by the memory location bound to the engine.

## Example

  ```cpp
  #include "tensor_api/tensor.h"

  using namespace asc::te;

  // Example 1: Create a global_tensor using a GM pointer and layout.
  auto gm_ptr = make_mem_ptr<location::gm, half>(gm_addr);
  auto gm_layout = make_layout(make_shape(32, 32), make_stride(32, 1));
  auto gm_tensor = make_tensor(gm_ptr, gm_layout);

  // Example 2: Create a local_tensor using a Local Memory pointer and layout.
  constexpr int tile_num = 4;
  __cbuf__ half data_ptr[tile_num]; // Initialize.
  auto ptr = make_mem_ptr(data_ptr);
  auto layout = make_frame_layout<nz_layout_ptn, half>(32, 32);
  auto tensor = make_tensor(ptr, layout);

  // Example 3: Create a tensor using a pointer and layout shape.
  auto tensor2 = make_tensor(ptr, make_shape(32, 32), make_stride(32, 32));
  ```
