## Description

The header file path is `"c_api/atomic/scalar_atomic.h"`.

Performs an atomic increment operation on a `uint32_t` or `uint64_t` element in Global Memory pointed to by `address`. It reads the old value `old_value` of the element, computes the new value `new_value` according to the following formula, and writes it back:

$$
new\_value = (old\_value >= val) ? 0 : (old\_value + 1)
$$

The API returns `old_value`. The entire read, comparison, and write-back process is atomic.

## Prototype

```c
__aicore__ inline <dtype> asc_atomic_inc(__gm__ <dtype>* address,
                                         <dtype> val)
```

### Data Types Supported by dtype

The data types supported by dtype are `uint32_t` and `uint64_t`.

### Prototype Example

```c
// Example: atomic increment of a uint32_t scalar.
__aicore__ inline uint32_t asc_atomic_inc(__gm__ uint32_t* address,
                                          uint32_t val)
```

**Table 1** Parameter description

## Return Value

The original data at the `address` before the computation.

## Pipeline Type

PIPE_S

## Constraints

- With the compiler's automatic synchronization feature enabled, the compiler can automatically insert synchronization between PIPE_MTE2/PIPE_MTE3 and PIPE_S. However, asc_atomic_inc is a scalar computation. If there is a data dependency with the transfer units (MTE2/MTE3) when reading from or writing to GM, the compiler cannot automatically insert synchronization, so you need to manually insert synchronization as appropriate.
- Scalar atomic operations bypass the DCache. Call [asc_dcci](../../cache_ctrl/asc_dcci.md) to ensure consistency between GM and the DCache.

```cpp
#include <cstdint>
#include <iostream>
#include <vector>
#include "c_api/asc_simd.h"
#include "acl/acl.h"

namespace {
template <typename T>
void print_data(const char* label, const std::vector<T>& values)
{
    std::cout << label << ":";
    const size_t count = values.size() < 8 ? values.size() : 8;
    for (size_t i = 0; i < count; ++i) std::cout << ' ' << +values[i];
    if (values.size() > count) std::cout << " ...";
    std::cout << std::endl;
}

constexpr uint32_t ELEMENTS = 8;

__global__ __vector__ void asc_atomic_inc_kernel(__gm__ uint32_t* output)
{
    asc_init();
    // Ensure that the data in the target cache line has been written back before the atomic access to GM.
    asc_dcci_single(output);
    asc_sync_data_barrier(mem_dsb_t::DSB_ALL);
    const uint32_t old_value = asc_atomic_inc(output, 20U);
    asc_sync_data_barrier(mem_dsb_t::DSB_ALL);
    // Atomic operations bypass the DCache. Before a normal scalar write, invalidate the stale copy in the target cache line.
    asc_dcci_single(output);
    asc_sync_data_barrier(mem_dsb_t::DSB_ALL);
    output[1] = old_value;
    // Write back the dirty cache line generated by a normal scalar write to GM.
    asc_dcci_single(output);
    asc_sync_data_barrier(mem_dsb_t::DSB_ALL);
}
} // namespace

int main()
{
    std::vector<uint32_t> input = {10, 0};
    std::vector<uint32_t> golden = {11, 10};
    input.resize(ELEMENTS, 0);
    golden.resize(ELEMENTS, 0);
    std::vector<uint32_t> output(ELEMENTS, 0xffffffffU);
    aclInit(nullptr);
    aclrtSetDevice(0);
    uint32_t* output_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&output_device), (ELEMENTS) * sizeof(uint32_t),
        ACL_MEM_MALLOC_HUGE_FIRST);
    aclrtMemcpy(output_device, input.size() * sizeof(uint32_t), input.data(), input.size() * sizeof(uint32_t),
        ACL_MEMCPY_HOST_TO_DEVICE);
    asc_atomic_inc_kernel<<<1, 0>>>(output_device);
    aclrtSynchronizeDevice();
    aclrtMemcpy(output.data(), output.size() * sizeof(uint32_t), output_device, output.size() * sizeof(uint32_t),
        ACL_MEMCPY_DEVICE_TO_HOST);
    print_data("Input", input);
    print_data("Output", output);
    print_data("Golden", golden);
    const bool passed = output == golden;
    std::cout << (passed ? "[Success] asc_atomic_inc passed." : "[Failed] asc_atomic_inc failed.") << std::endl;
    aclrtFree(output_device);
    aclrtResetDevice(0);
    aclFinalize();
    return passed ? 0 : 1;
}
```
