# HF32

<!-- md-trans-meta sourceCommit=c891f0c5d5b2ac25c5683ff40810fa381d654ece translatedAt=2026-10-21T03:04:32.922Z pushedAt=2026-10-28T12:21:43.286Z nl=2 -->

**Feature Description:**

The core function of HF32 is as follows: when both input matrices A and B are of the fp32 data type and the HF32 switch is enabled, the fp32 data is converted and rounded to the HF32 (half-fp32) format before cube multiplication is performed. This approach improves the computational performance of Mmad (f322f32) APIs, but introduces a certain loss of numeric precision. Note that although intermediate computation uses the HF32 format, the final result is still output in the fp32 format to ensure compatibility with subsequent processing.

The impact of enabling HF32 on performance is as follows:

<!-- npu="A3,910b" id3 -->
- For the following product models:

  <!-- npu="A3" id4 -->
  Atlas A3 products
  <!-- end id4 -->
  <!-- npu="910b" id5 -->
  Atlas A2 products
  <!-- end id5 -->
  Enabling HF32 doubles the computational performance of Mmad (f322f32) APIs.
<!-- end id3 -->

<!-- npu="950" id2 -->
- For Ascend 950PR&950DT products, enabling HF32 increases the computational performance of Mmad (f322f32) APIs by eight times.
<!-- end id2 -->

Rounding mode description: The rounding mode used in the fp32-to-HF32 conversion is configured by the [asc_set_hf32_round_mode](../asc_set_hf32_round_mode.md) API. When HF32 mode is enabled and asc_hf32_round_mode is set to NEAREST_AWAY, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounding away from zero. When asc_hf32_round_mode is set to NEAREST_EVEN, FP32 is rounded to HF32 by rounding to the nearest value, with ties rounding to even.

**Examples:**

```cpp
// Enable HF32 mode.
asc_enable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_AWAY);
asc_mmad(c, a, b, m, k, n, asc_unit_flag_mode::DISABLE,
         false, false, true);
// Disable HF32 mode and restore the default rounding mode.
asc_disable_hf32();
asc_set_hf32_round_mode(asc_hf32_round_mode::NEAREST_EVEN);
```
