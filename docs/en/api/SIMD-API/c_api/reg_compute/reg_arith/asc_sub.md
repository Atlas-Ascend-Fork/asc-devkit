## Description

The header file path is `"c_api/reg_compute/compute/reg_arith.h"`.

This API performs an element-wise subtraction operation on the source operands `src0` and `src1` based on `mask`, and writes the result to the destination operand `dst`.

The carry flag (carry/borrow flag) indicates an addition carry or no borrow in subtraction. Subtraction is implemented in hardware through two's complement addition. This API can mark in `carry` (mask register) whether each two's complement addition generates a carry. If the highest bit of the bitwise sum of `src0`, `~src1`, and `33'b1` has a carry, 1 is written to the lowest bit of each 4-bit group at the corresponding position in `carry`; otherwise, 0 is written.

**[Subtraction Without Borrow Output](#subtraction-without-borrow-output)**: Single destination operand. The vector data register receives the subtraction result. The calculation formula is as follows:

$$
dst_i = src0_i - src1_i
$$

**[Subtraction With Borrow Output](#subtraction-with-borrow-output)**: Dual destination operands. Hardware processes values as 32-bit unsigned numbers. The vector data register receives the lower 32 bits of the two's complement addition sum, and the destination mask register receives the carry output generated by the two's complement addition of each element. The calculation formula is as follows:

$$
\{carry_i, dst_i\} = \{1'b0, src0_i\} + \{1'b0, \sim src1_i\} + 33'b1
$$

![](../../../../figures/asc_sub.png)

For applicable scenarios of the output `carry`, see [asc_subc Description](asc_subc.md#description).

This API is a Reg vector computation API and takes effect only on AIV.

## Parameters

### Subtraction Without Borrow Output

**Table 1** Parameters

| Parameter | Input/Output | Description |
|---|---|---|
| dst | Output | Destination operand (vector data register), used to store the subtraction result. Applicable only to the prototype that outputs the result through a reference parameter. |
| src0 | Input | Source operand (vector data register). |
| src1 | Input | Source operand (vector data register). |
| mask | Input | Source operand mask (mask register), which indicates which elements participate in the computation. A value of 1 at the corresponding position means the element participates in the computation, and 0 means it does not. Elements not selected by the mask are set to zero in the output. |

### Subtraction with Borrow Output

**Table 2** Parameters

| Parameter | Input/Output | Description |
|---|---|---|
| carry | Output | Destination operand (mask register), used to store the subtraction borrow output. No borrow in subtraction is equivalent to a carry in two's complement addition. |
| dst | Output | Destination operand (vector data register), used to store the lower 32 bits of the computation result. |
| src0 | Input | Source operand (vector data register). |
| src1 | Input | Source operand (vector data register). |
| mask | Input | Source operand mask (mask register), which indicates which elements participate in the computation. A value of 1 at the corresponding position means the element participates in the computation, and 0 means it does not. Elements not selected by the mask are set to zero in the output. |

For details about vector data registers and mask registers, see [Register Type Definition](../../defs/type/data_type_definition.md).

## Return Value

- The prototype that outputs the result through a reference parameter has no return value.
- The prototype that returns the result through the function return value returns the subtraction result without borrow, and the return value type is the same as the source operand type.
- Subtraction with borrow output supports only outputting the result through a reference parameter and has no return value.

## Constraints

### General Constraints

- For the general constraints on Reg vector computation C APIs, see [General Constraints](../overview.md#general-constraints).

### Constraints for Subtraction Without Borrow Output

- When integer dtype subtraction overflows, it is handled using the wrap-around strategy: signed types wrap around to the minimum or maximum value of the corresponding dtype (MIN-1->MAX, MAX+1->MIN), and unsigned types underflow and wrap around to the maximum value of the corresponding dtype (0-1->UMAX).
- Floating-point dtype (half, bfloat16_t, float) subtraction follows IEEE 754 floating-point subtraction semantics. Overflow and invalid inputs (such as nan and inf) are handled according to floating-point arithmetic rules.

### Constraints for Subtraction with Borrow Output

- Only `uint32_t` is supported.
- The operation outputs the complete computation result (including the no-borrow flag) and is not affected by [asc_set_ctrl](../../spr/asc_set_ctrl.md). The hardware does not saturate or truncate the output.
- The difference is truncated to 32 bits: `dst` is written with `(src0_i + ~src1_i + 0b1) & 0xFFFFFFFF`, and the portion exceeding 32 bits is not retained.

```c
#include <cstdint>
#include <iostream>
#include <vector>

#include "c_api/asc_simd.h"
#include "acl/acl.h"

namespace {
template <typename T>
void print_data(const char* label, const std::vector<T>& values)
{
    std::cout << label << ":";
    const size_t count = values.size() < 8 ? values.size() : 8;
    for (size_t i = 0; i < count; ++i) std::cout << ' ' << +values[i];
    if (values.size() > count) std::cout << " ...";
    std::cout << std::endl;
}

template <typename T>
bool compare_data(const std::vector<T>& actual, const std::vector<T>& expected)
{
    return actual == expected;
}

constexpr uint32_t ELEMENT_COUNT = 64;

__simd_vf__ inline void sub_vf(__ubuf__ float* dst, __ubuf__ float* src0, __ubuf__ float* src1)
{
    vector_float dst_reg;
    vector_float src0_reg;
    vector_float src1_reg;
    uint32_t count = ELEMENT_COUNT;
    vector_bool mask = asc_update_mask_b32(count);
    asc_loadalign(src0_reg, src0);
    asc_loadalign(src1_reg, src1);
    asc_sub(dst_reg, src0_reg, src1_reg, mask);
    asc_storealign(dst, dst_reg, mask);
}

__global__ __vector__ void asc_sub_kernel(__gm__ float* dst, __gm__ float* src0, __gm__ float* src1)
{
    asc_init();
    __ubuf__ float dst_local[ELEMENT_COUNT];
    __ubuf__ float src0_local[ELEMENT_COUNT];
    __ubuf__ float src1_local[ELEMENT_COUNT];

    asc_copy_gm2ub_align(src0_local, src0, ELEMENT_COUNT * sizeof(float));
    asc_copy_gm2ub_align(src1_local, src1, ELEMENT_COUNT * sizeof(float));
    asc_sync_notify(PIPE_MTE2, PIPE_V, EVENT_ID0);
    asc_sync_wait(PIPE_MTE2, PIPE_V, EVENT_ID0);
    sub_vf(dst_local, src0_local, src1_local);
    asc_sync_notify(PIPE_V, PIPE_MTE3, EVENT_ID0);
    asc_sync_wait(PIPE_V, PIPE_MTE3, EVENT_ID0);
    asc_copy_ub2gm_align(dst, dst_local, ELEMENT_COUNT * sizeof(float));
    asc_sync();
}

} // namespace

int main()
{
    std::vector<float> src0(ELEMENT_COUNT);
    std::vector<float> src1(ELEMENT_COUNT);
    std::vector<float> output(ELEMENT_COUNT, 0.0f);
    std::vector<float> golden(ELEMENT_COUNT);

    for (uint32_t i = 0; i < ELEMENT_COUNT; ++i) {
        src0[i] = static_cast<float>(i) * 0.5f;
        src1[i] = static_cast<float>(ELEMENT_COUNT - i) * 0.25f;
        golden[i] = src0[i] - src1[i];
    }

    aclInit(nullptr);
    aclrtSetDevice(0);
    float* src0_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&src0_device), (ELEMENT_COUNT) * sizeof(float),
        ACL_MEM_MALLOC_HUGE_FIRST);
    float* src1_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&src1_device), (ELEMENT_COUNT) * sizeof(float),
        ACL_MEM_MALLOC_HUGE_FIRST);
    float* dst_device = nullptr;
    aclrtMalloc(reinterpret_cast<void**>(&dst_device), (ELEMENT_COUNT) * sizeof(float),
        ACL_MEM_MALLOC_HUGE_FIRST);
    aclrtMemcpy(src0_device, src0.size() * sizeof(float), src0.data(), src0.size() * sizeof(float),
        ACL_MEMCPY_HOST_TO_DEVICE);
    aclrtMemcpy(src1_device, src1.size() * sizeof(float), src1.data(), src1.size() * sizeof(float),
        ACL_MEMCPY_HOST_TO_DEVICE);

    asc_sub_kernel<<<1, 0>>>(dst_device, src0_device, src1_device);
    aclrtSynchronizeDevice();
    aclrtMemcpy(output.data(), output.size() * sizeof(float), dst_device, output.size() * sizeof(float),
        ACL_MEMCPY_DEVICE_TO_HOST);

    print_data("Input src0", src0);
    print_data("Input src1", src1);
    print_data("Output", output);
    print_data("Golden", golden);
    const bool passed = compare_data(output, golden);
    std::cout << (passed ? "[Success] asc_sub passed." : "[Failed] asc_sub failed.") << std::endl;
    aclrtFree(dst_device);
    aclrtFree(src0_device);
    aclrtFree(src1_device);
    aclrtResetDevice(0);
    aclFinalize();
    return passed ? 0 : 1;
}
```
