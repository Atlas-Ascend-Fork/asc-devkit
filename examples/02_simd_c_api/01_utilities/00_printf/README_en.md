# Printf Samples

## Overview

This sample shows how to use the Ascend C printf interface and the simd_vf printf interface.

## Sample List

| Directory | Description | Supported Products |
| --- | --- | --- |
| [simple_printf](./simple_printf) | Uses static buffer programming mode to implement matrix multiplication, showing basic usage of the printf interface | Ascend 950PR&950DT products |
| [simd_vf_printf](./simd_vf_printf) | Uses vector programming mode, showing basic usage of the simd_vf printf interface | Ascend 950PR&950DT products |
